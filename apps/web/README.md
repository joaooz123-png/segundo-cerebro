# RG Knowledge OS Web

Frontend para pesquisa, auditoria e continuidade dos projetos.

## Stack sugerida
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query

## Telas MVP
1. Busca global
2. Context Pack
3. Caso/instituição
4. Timeline
5. Correções permanentes
6. Conflitos e duplicidades
7. Fontes e anexos

## Regra de UX
A interface deve mostrar claramente:
- fato documentado
- relato
- hipótese
- pendência
- conflito
- versão substituída

Nenhuma consolidação deve ocorrer sem revisão humana quando houver conflito probatório.
