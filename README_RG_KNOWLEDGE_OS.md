# RG Knowledge OS

Sistema versionado de conhecimento para preservar continuidade entre conversas, projetos e documentos.

## Componentes

- Guia Mestre: regras permanentes de trabalho.
- Índice Mestre: mapa dos domínios e objetos.
- Base Mestra: fatos e entidades rastreáveis.
- Sistema de Recuperação: duas IAs, uma recuperadora e outra redatora.
- Google Drive: arquivos originais e anexos privados.
- Wisebase: busca semântica e recuperação rápida.

## Segurança

Este repositório é público. Não inserir CPF, dados médicos, contratos, provas, extratos, mensagens privadas ou documentos jurídicos sensíveis. Esses materiais devem permanecer no Google Drive privado ou em repositório privado futuro.
